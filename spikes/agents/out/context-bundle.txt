# sauravsinghchandel.com

Portfolio of Saurav Singh Chandel, built from the Claude Design "sauravsinghchandel.com — revamp" canvas.

- **`/` Cosmos mode**: a ray-traced WebGL black hole hero (with a 2D fallback), scroll-driven warp jumps between sections, projects in orbit, a constellation of hobbies, an aim-check mini-game, a "mission control" terminal and a hidden easter egg.
- **`/simple` Simple mode**: a plain, fast résumé page.

## Stack

Next.js 16 (App Router, fully static), React 19, strict TypeScript, plain CSS, `next/font` (Archivo, Schibsted Grotesk, JetBrains Mono). Vitest for logic, Playwright (installed Chrome) for the browser tests.

## Run

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # static export to ./out
npm run preview    # serve ./out with Cloudflare's local runtime (wrangler dev)
```

Checks: `npm run typecheck`, `npm run lint`, `npm test`, `npm run test:e2e` (run `npm run build` first; tests use `wrangler dev`).

## Deploy to Cloudflare

The site is a static export served by Cloudflare Workers static assets (`wrangler.jsonc`).

**From your machine:** `npx wrangler login` once, then `npm run deploy`.

**From GitHub (auto-deploy on push):** Cloudflare dashboard → Workers & Pages → Create → Import a repository → pick this repo. Build command `npm run build`, deploy command `npx wrangler deploy`. Node 22 comes from `.nvmrc`.

Then add `sauravsinghchandel.com` under the Worker's Settings → Domains & Routes.

## Where things live

- `src/content/site.ts` — name, links, email, résumé and thesis links, and `aimBestMs` (your best aim-check time; `null` hides the line).
- `src/content/cosmos.ts` — projects, hobbies, timeline, games and warp-jump labels.
- `src/app/simple/page.tsx` — résumé content.
- `src/lib/cosmos/` — black hole renderer and shader, warp gates, terminal commands, audio, aim-check helpers.
- `src/components/cosmos/` — the Cosmos page sections.
- `src/app/globals.css` — all styles.
