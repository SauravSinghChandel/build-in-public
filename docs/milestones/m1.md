# M1 — Foundation

Built:
- Strict TypeScript pnpm workspace: Hono/SQLite server, React 19/Vite client, shared Zod schemas/API types.
- Local session authentication, Host/Origin protection, safe paths and HOME-only directory autocomplete.
- Git discovery/info/log/count caching, empty/detached/merge/binary handling, saved-date fallback for lost markers.
- WAL registry, numbered backed-up migrations, tracking/untracking, missing-folder status and automatic/manual relinking.
- Ported the storage spike with atomic/fsynced writes, locks, exclusions, context opt-in/out, Markdown editing and tar.gz backups.
- Graphite/amber UI: collapsible navigation, command palette, project list/add dialog, day-grouped timeline, selection/paging/shared markers.
- Context autosave, project settings, Folders/Agents/Appearance/Storage/About, persisted theme; Stories/Media placeholders.
- Compiled bip CLI: start, doctor, backup; architecture/run/security notes in docs/architecture.md.

Verification (2026-11-04, final source):
- typecheck: PASS across server, web, shared and test sources.
- test: PASS, 32 Vitest unit/integration tests using disposable repositories.
- test:e2e: PASS, 1 Playwright production-server core loop with 3 generated repositories and temporary HOME/BIP_HOME.
- bip doctor: PASS, 8/8 checks; Node 22.22.1, Git, FFmpeg, cached Chromium, agent versions, writable data and free port.
- Codex sign-in detected; Claude sign-in explicitly unknown, with no model calls.
- Production build: PASS. Dark/light screenshots inspected; git diff --check clean.

Deviations / decisions:
- tsx for development and compiled JavaScript for production because system Node cannot strip TypeScript.
- BIP_HOME also contains config.json when set, keeping portable/test runs isolated; otherwise config uses XDG_CONFIG_HOME.
- Added saved marker date for pruned-history fallback and a registry display-name cache for missing folders.
- Project scan depth is managed through app Settings → Folders (the project settings screen explains this).

Known limitations:
- Inherited spike caveats: worktrees share excludes; malformed/PID-reused locks fail closed; opt-out cannot untrack committed context.
- Backups are manual snapshots, not multi-file transactions; git clean -fdx/deleting a repo can destroy .bip/.
- Mobile layouts/reduced motion are implemented; the automated browser scenario exercises desktop Chromium.
- Vite reports a non-blocking >500 kB client bundle warning. Story creation is intentionally disabled for M1.
